# 深掘りの記録の形（`wine_dossiers`）

1本のワインの深掘りを1件として残す。将来、写真とテイスティングのメモから深掘りするアプリを作るときの、記録の土台にもなる形にしてある。

**値ごとに根拠を付ける。** 根拠は「ラベル」「造り手」「輸入元」「公的機関」「販売店・評論」「推測」のどれか。同じ項目で値が食い違ったら、採った値と、採らなかった値の両方を残す。

| まとまり | 項目 |
| --- | --- |
| 特定 | 生産者（旧名・別表記も）、キュヴェ名、ヴィンテージ、国・産地・呼称、等級、輸入元 |
| 写真 | 写真の種類（表ラベル／裏ラベル／輸入者のシール／栓・キャップ／グラス）、書き起こし、読めなかった箇所 |
| 畑 | 品種と比率、土壌、標高、斜面の向き、樹齢、面積、収量（hl/ha と、t/ha の換算値・前提）、農法・認証 |
| 年の天候 | 要約（2〜3文）、月別の気温と降水量、積算温度と平年との差、比べた自分の地域の値、使ったデータ源 |
| 醸造 | 工程の列（工程、中身、根拠）、亜硫酸（瓶詰め前・総量）、度数、瓶詰め日、栓 |
| 造り手 | 経歴の要約、農法や造りを切りかえた年 |
| 量と値段 | 本数、価格（現地・日本） |
| テイスティング | 飲んだ日、場所、一緒に飲んだ人の有無、自分のメモ（外観・香り・味・余韻と自由記述）、造り手や輸入元のノート、照らし合わせの仮説 |
| 示唆 | 真似できること、条件が違って効きにくいこと、小さく試すなら |
| 次に掘れること | 問いの一覧と、それぞれ済んだか |
| 出典 | 資料の種類、題名、URL、どの値の根拠か |
