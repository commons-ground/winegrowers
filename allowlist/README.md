# ワイン関連サイトの許可リスト

ground の `core:web-access`（Webの読み込み許可）への上乗せです。ground の許可リスト（政府・自治体・大学・国際機関など）に、ワイン生産者がよく読む公的・学術・業界団体のサイトを足します。

入れる基準は ground と同じです。**読むだけで、利用者が書き込めないサイト**だけを入れ、誰でも書き込める場所（掲示板、SNS、ブログ、Wikipedia など）やログインが要るサイトは入れません。

| ファイル | 中身 |
| --- | --- |
| `make_allowlist.py` | リストを作るスクリプト。サイトごとに、何のサイトかを書いてある。足すときはここを直して動かす |
| `claude-code-settings.json` | Claude Code の設定に貼る形 |
| `sites.txt` | ブラウザや組織の設定に貼る形（1行1つ） |

設定するのは人です（1回だけ）。設定の場所は ground の web-access の「人が設定する場所」を見てください。Claude は設定ファイルに許可を書き込みません。

サイトを足したいときは、`make_allowlist.py` に「何のサイトか」と一緒に書き、プルリクエストに「人の確認」のラベルを付けます。
