## 覚えていること

コモンズのAI（Discord の `/ai` と GitHub の `@claude`）が、やりとりから覚えたこと。どちらの入口のAIも、答える前にこれを読む。

- 足し方：AIの返事にある「〔覚えておく〕」の行を、core:harvest で拾って1行ずつ足す。GitHub のAIがこのリポジトリで呼ばれたときは、AIが自分でプルリクエストを出す
- 書かないもの：事業データ（人名以外の個人情報、金額、取引先、各自の Notion や Drive の URL）、その場かぎりの話、推測
- 整理：重なる行は1行にまとめ、古くなった行は消す。スキルにすべき手順になったら、スキルに移してここから消す

（まだ何もありません）
